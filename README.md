# 🐱 MeWGic — Mobile Puzzle Game

**A cat-themed mobile puzzle game developed with Unity and C#.**

MeWGic is a mobile puzzle game combining color-sorting mechanics, interactive gameplay, level progression, and reward systems.

The project focuses on mobile game development, gameplay programming, user experience, and application testing.

Platform: Android & iOS

Engine: Unity 6000

Language: C#

Rendering: Universal Render Pipeline (URP)

Development Status: In active development and testing for Android and iOS.

---

## 🎮 Game Features

- **Color Sorting Gameplay:** Interactive puzzles with dynamic bottles and color-matching mechanics.
- **Level Progression:** Level management, unlocking, and persistent player progress.
- **Power-ups:** Undo, Hint, Extra Bottle, and Shuffle mechanics.
- **Reward Systems:** Stars, collectible rewards, and daily activities.
- **Interactive Interface:** Custom-designed game screens, navigation, and visual feedback.
- **Progress Saving:** Local save management with backup and recovery mechanisms.
- **Mobile Optimization:** Android portrait-mode gameplay and mobile-focused interface design.

## 🧠 Technical Highlights

**Gameplay Architecture**

The project separates gameplay mechanics, progression systems, user interface components, and player data management.

**Data Persistence**

Player progress is stored locally with backup and recovery mechanisms designed to reduce the risk of data loss.

**Game Testing**

The project includes Unity Editor validation tools for checking gameplay, rewards, level progression, and other core systems.

**User Experience**

The game uses interactive tutorials, visual feedback, and mobile-oriented UI design to make gameplay accessible.
