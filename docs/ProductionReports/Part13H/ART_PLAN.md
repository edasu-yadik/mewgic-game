# PART13H — Arcane Library sanat planı

Yalnız11. ada501–550. Gerçek03_Map ve onaylı Sky Castle stil/kamera referansı; ekteki küçük örnek üretim girdisi veya ayrı talimat değildir.

- Kompozisyon: bulutların üstünde taş/altın uçan akademi terası; arkada ayrı büyük kütüphane/akademi. Ön sakin taş rota5 gerçek bölüm grubuna alan bırakır. Kristal merdiven/yıldızlı geçit ve altın-mavi ışık, az miktarda bitki.
- Mimari: mor-altın kuleler, açık kemerli büyük salon içinde görünür dev kitap rafları; sıcak pencere, mavi kristal giriş merdiveni. Kütüphane kimliği sıradan saraydan ayırt edilmeli.
- Kaynaklar: saydam taban PNG, ayrı akademi PNG, bağımsız açık kitap PNG (3 instance), saydam ince sihir halkası PNG (2 instance). Katmanlar PART13A dokuz sıra; düğüm/sandık MapWorld sahibi.
- Hareket:3 kitabın yavaş dikey salınım/hafif eğimi;2 halkanın düşük alpha nefes alması; ayrı pencere/kristal ışığı. Sayfa/rig/fizik/sıvı simülasyonu veya pahalı gerçek zamanlı3D yok.
- Başlangıç bütçe üst sınırı: taban2048, akademi1024, kitap512, halka256; ASTC6×6, ReadWrite/mipmap kapalı. Gerçek kaynak/runtime boyutları ve payload son raporda.
- Kabul:500→501/550→551 gerçek UI gameplay,50 kimlik, kilit/yıldız/kayıt/pin/sandık; görev/navigasyon,3 oran/SafeArea, raycast,5 görünüm/40 düğüm ve görünür sanat release, sessiz Editor performansı, gerçek Game View karşılaştırması. Yeni build yok.
